# BlankNote 0.2.0 验证记录

日期：2026-10-12。环境：macOS 26.6.2、Apple Silicon、Swift 6.3.3。

## 已通过

- XCTest：19 项，0 失败。新增旧格式读取不重写、分组排序、撤销重做、恢复身份与创建时间、笔记独立性、历史边界和保存失败后重试覆盖。
- Release 构建无编译警告；应用签名、Info.plist、安装 / 更新 / 测试脚本语法检查通过。
- 独立应用标识 `org.blanknote.BlankNote.UITest`、独立数据目录 `/tmp/BlankNote-UI.<随机标识>` 中实测回车添加、双击原地编辑、回车保存、Esc 取消。
- 点击撤销编辑、⌘Z 撤销完成、⌘⇧Z 重做完成均生效。
- 拖动第二条到第一条之前，实际列表顺序改变，出现「撤销调整顺序」。
- 浅色与深色窗口已视觉检查；外观菜单可切换深色。
- 随手记可输入多行并折叠，折叠后显示内容预览。
- 测试版本多次重启后，待办顺序与内容正确加载；正式版持续运行，未被测试写入。
- 开发前已备份正式数据；开发后正式文件 SHA-256 与备份相同，原有记录未改变。
- 解锁后验证：未提交的新待办草稿在重启后恢复，折叠状态与排序也已恢复；原生 ⌃⌥N 菜单快捷键可触发窗口切换并重新聚焦草稿。
- 已正常退出旧版，执行 `scripts/update.sh` 完成正式升级。新版界面载入原有待办与完成状态，正式笔记文件与更新前备份逐字节相同。
- 更新已保留旧应用、最新笔记、上一版备份及偏好设置，位于用户数据目录下的 `Upgrade Backups/<日期-唯一标识>/`；用户登录启动偏好没有被修改。

## 验证范围限制

- Carbon 全局快捷键注册成功；当前自动化工具的定向按键尚不能确认跨应用的物理全局热键行为。已补充原生菜单快捷键用于应用内切换。
- 没有修改用户的登录启动开关；完整注销重登、多显示器和不同全屏应用仍需对应环境验收。
- GitHub CI 尚未在远端执行，开发构建未进行 Apple 公证。

## 数据保护

初始私有备份在工作区 `backups/` 中，已加入 `.gitignore`，不属于开源发布内容。更新脚本还会在用户数据目录的 `Upgrade Backups/` 内生成带唯一名称的完整备份，并拒绝在应用仍运行时覆盖安装。任何测试都不得对正式笔记执行添加、完成、编辑或删除操作。

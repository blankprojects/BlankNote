# 测试与验收

## 自动化

`zsh scripts/test.sh` 验证空输入、Unicode、持久化、完成与恢复、编辑、精确删除、多行笔记、无效 ID、备份恢复、损坏文件保护和不可写路径。还覆盖旧版文件读取不重写、撤销 / 重做（不回退随手记）、分组排序、无效拖动、历史边界与保存失败后重试。每个测试使用独立临时目录，不访问用户笔记。

`zsh scripts/build.sh` 构建 release 应用并生成图标、执行本机 ad-hoc 签名。CI 在 macOS 上执行测试、构建、plist 与签名检查，保存开发构建 zip。

## 界面与系统验收

使用 `zsh scripts/run-ui-test.sh` 启动独立应用标识和测试数据目录：

- 首次启动：窗口可见，菜单栏有入口，Dock 不常驻额外图标。
- 输入中文、emoji、多行较长内容；回车添加；空白无法添加。
- 勾选完成、切换列表、恢复事项，重启后状态一致。
- 编辑事项；删除取消后原项保留，确认后仅删除所选项。
- 双击原地编辑，回车保存、Esc 取消；失去焦点保存非空修改。
- 拖动首 / 中 / 末行排序，切换已完成后排序，撤销与重做顺序正确。
- 分别从事项文字和左侧手柄开始拖动，确认顺序改变且窗口位置不变；拖动顶部标题区应能移动窗口，图钉、收起按钮与双击文字编辑仍有效。
- 撤销修改和完成状态，菜单与 ⌘Z / ⌘⇧Z 可用；编辑文字时优先处理文字撤销。
- ⌃⌥N 唤出并聚焦、再次隐藏；新增输入草稿在重启后保留。
- 切换浅色、深色与系统外观，检查文字对比度；收起随手记不改变内容。
- 随手记输入、全选、复制粘贴正常，重启后保留。
- 拖动窗口、调整大小、收起和展开；切换置顶后不抢夺其他应用输入。
- 菜单栏「显示 BlankNote」能重新找到窗口；跨桌面空间可见。
- 多显示器断开后，重新启动仍可找到窗口。
- 安装后用 `launchctl print gui/$(id -u)/org.blanknote.BlankNote` 检查服务运行。
- 升级前后比较正式 `notebook.json` 的 SHA-256；没有用户同时编辑时应完全一致，升级不得清空记录。
- 在没有未保存工作时手动注销并登录，确认自动启动。此项不能用服务状态检查代替。
- 在独立测试环境模拟异常退出，确认 launchd 重启；主动退出不自动重启。

完整重启、不同 macOS 版本、多显示器和所有全屏应用需要对应环境验收。实际通过的项目和未执行的项目记录在 `docs/VALIDATION.md`，不要把未运行的 CI 或手工项目标成通过。
